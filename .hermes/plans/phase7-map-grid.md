# Phase 7: Карта + адаптивная сетка — План реализации

> **Для Hermes:** следовать задачам по порядку. TDD где возможно. Перед каждой задачей спрашивать разрешение.

**Цель:** загрузка кастомного изображения как карты, адаптивная сетка, синхронизация по сети.

## Задача 1: MapController

**Файл:** `Assets/Scripts/Networking/MapController.cs` (новый, NetworkBehaviour)

**Функционал:**
- Загрузка PNG/JPG через Tex
- Масштаб через InputField (1.0 / 1.25 / 0.75)
- Движение: средняя кнопка мыши + drag
- Поворот: клавиша R (по 90°)
- Сброс: кнопка Reset (или через поле масштаба)
- Plane подгоняется под аспект картинки

**Синхронизация:**
- Позиция/поворот: `NetworkTransform` (авто)
- Масштаб: `NetworkVariable<float>`
- Late-join: `OnNetworkSpawn` применяет сохранённый масштаб

**Управление:** только хост (`IsOwner`)

## Задача 2: MapSync — передача текстуры

**Файл:** `Assets/Scripts/Networking/MapSync.cs` (новый, NetworkBehaviour)

**Функционал:**
- `SendMapToAll(byte[] pngData)` — хост вызывает после загрузки
- Разбивка на чанки по 4KB
- Передача через `CustomMessagingManager` (именованные сообщения)
- Сборка чанков на клиенте → `Texture2D.LoadImage`
- Late-join: при подключении клиента сервер шлёт текущую текстуру

**Сообщения:**
- `MapChunk` — чанк данных (индекс + байты)
- `MapMeta` — метаданные (количество чанков, размер)
- `RequestMap` — late-join клиент запрашивает карту

## Задача 3: GridManager.SetBounds

**Файл:** `Assets/Scripts/GridManager.cs` (модификация)

**Новый метод:**
```csharp
public void SetBounds(Bounds mapBounds)
```
- Перестраивает сетку под границы карты
- Сетка рисуется только внутри bounds
- Обновляет `CellSize`, `GridWidth`, `GridHeight`
- Стены — по периметру bounds
- Синхронизация: `ClientRpc SetBoundsClientRpc`

## Риски

| Риск | Решение |
|---|---|
| Большая картинка (20MB) | Чанки 4KB, сжатие JPG quality 70% |
| Late-join не видит карту | `OnClientConnected` → сервер шлёт текстуру |
| Сетка мерцает при движении | Debounce 0.2с перед перестроением |
| Клиент не может управлять | `IsOwner` проверка, только хост |

## Задача 4 (будущее): Токены

Токены будут использовать публичный API `GridManager`:
- `WorldToCell(pos)` — привязка к клетке
- `CellToWorld(cell)` — центр клетки
- `CellSize` — размер клетки
- `MapBounds` — границы (токены только внутри)

Для фазы 7 достаточно метода `SetBounds(Bounds)` — всё остальное уже есть.
