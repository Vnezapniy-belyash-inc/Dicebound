# Phase 8: Токены (Token System)

> **Для Hermes:** следовать задачам по порядку. Перед каждой — спрашивать.

**Цель:** Токены персонажей/NPC/существ на карте. Сетевые, с кастомными картинками, привязка к сетке.

---

## Архитектура

```
Token (GameObject)
  ├── NetworkObject
  ├── NetworkTransform (Authority=Owner)
  ├── Body (Cylinder: Radius=0.45, Height=0.08)
  ├── Portrait (Quad: Scale=0.7×0.7, Rot X=90°, Y=0.041)
  ├── MeshCollider (на Cylinder)
  └── TokenController (NetworkBehaviour)
```

**Шайба:** Cylinder (серый), сверху Quad для портрета.

**Картинка:** дочерний Quad, текстура загружается через контекстное меню.

---

## Функционал

| Действие | Кто может | Как |
|---|---|---|
| Создать токен | Хост + клиенты | Кнопка на панели / хоткей |
| Загрузить картинку | Только создатель | ПКМ → контекстное меню → «Загрузить изображение» |
| Двигать токен | Все | Drag (как кубики) |
| Привязка к сетке | Авто | Snap to grid при отпускании |
| Контекстное меню | Все (но загрузка только для создателя) | ПКМ по токену |

## Задачи

### Задача 0: Контекстное меню (UI)

- Кастомное контекстное меню (как в Windows: список опций)
- ПКМ по токену → появляется рядом с курсором
- ПКМ в пустоту → закрывается
- Пункт: «Загрузить изображение» (только если `IsOwner`)
- В будущем добавятся: «Удалить», «Свойства», «Дублировать»

### Задача 1: TokenController

- `NetworkBehaviour` на префабе токена
- `RequestOwnership()` — любой может захватить для движения
- `SnapToGrid()` — привязка к центру клетки
- `LoadImage(byte[])` — загрузка картинки (только `IsOwner`)
- `ApplyImageLocal(byte[])` — для клиентов (получают по сети)
- Синхронизация: картинка через `ClientRpc` (как MapSync, но проще — JPEG q50)

### Задача 2: Префаб токена

- Cylinder + Quad для портрета (без ободка)
- Material: базовый цвет для Cylinder, прозрачный для Quad
- Настроить в Editor

### Задача 3: Спавн токенов

- Добавить кнопку/хоткей для создания токена
- Спавн через `NetworkDiceManager.RequestSpawnDie` (аналогично кубикам)
- Или отдельный `TokenManager.RequestSpawnToken()`
- Токен появляется в центре карты

### Задача 4: Drag и snap

- `TokenDragHandler` — перетаскивание токенов
- При отпускании: `SnapToGrid()` → позиция привязывается к центру клетки
- Или расширить `DiceDragHandler` для поддержки токенов

### Задача 5: Синхронизация

- Текстура токена: `EncodeToJPG(50)` → `ClientRpc` всем
- Late-join: через `OnClientConnectedCallback`

## Примечания

- Токены используют тот же `GridManager` API что и карта: `SnapToGrid`, `GetGridPosition`, `CellSize`
- `RequestOwnership` — как у кубиков: любой клиент может запросить владение через `ServerRpc`
- Картинки синхронизируются так же как карта (MapSync), но проще — JPEG q50 через RPC
