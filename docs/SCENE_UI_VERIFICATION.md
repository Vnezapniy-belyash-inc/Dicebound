# SCENE-UI-QA-01 — план и ход приёмки

Дата: 10.10.2026. Статус: **В работе**, задача не принята.

## Проверяемая реализация

Операции доступны в DmPanelUI.BuildScenePage: стрелки выбора, «Копировать», «Пустая», поле имени и «Имя ✓», «Удалить» с подтверждением. SceneFileStore сохраняет текущую сцену перед переключением, копирует данные сцены и бой, очищает переходы в новой копии, запрещает удаление последней сцены и удаляет входящие переходы к удалённой сцене. Наличие этого кода само по себе не является приёмкой.

## Обязательные сценарии

1. Настоящий Editor-host и отдельный Player: две сцены с различными картами, токенами, портретами, правами, приватностью и боем. Зафиксировать исходные данные обеих сцен.
2. Через UI создать пустую сцену; проверить пустые объекты и бой, переключение и согласованную загрузку клиента.
3. Через UI скопировать заполненную сцену: данные сохранены, ID сцены новый, копия независима, переходы копии пусты. Изменение копии не меняет оригинал.
4. Через поле и кнопку переименовать сцену; проверить пробелы, пустое имя, лимит 64 символа и сохранение после переключения.
5. Стрелками пройти сцены в обе стороны и через границу списка. Проверить карты, портреты, права, приватность и фактические записи инициативы после каждого перехода.
6. Через панель переходов перенести героя и NPC с портретом, правами и боевыми параметрами. Проверить отсутствие потери или дубликатов в исходной/целевой сцене и на клиенте.
7. Создать входящие переходы, отменить удаление, затем подтвердить удаление сцены. Проверить следующую активную сцену и очистку входящих переходов. Попытка удалить последнюю сцену сохраняет её данные и показывает понятное сообщение.
8. Сохранить и загрузить кампанию после операций; сравнить все оставшиеся сцены и библиотеки. Проверить клиент после загрузки.
9. Просмотреть реальные кадры UI, подтверждения удаления и сообщений; проверить доступность действий только мастеру.
