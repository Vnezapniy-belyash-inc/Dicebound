# Области и слои — ход проверки

9 октября 2026. Ветка codex/backlog-stabilization. Unity 6000.5.1f1.
AREA-01 и AREA-LAYER-01 приняты после перечисленных ниже проверок. Общая готовность: 6/19.

## Диагностика

На непрозрачной светлой карте квадрат получил корректные сетевые точки и пять вершин контура, но заливка клеток не была видна. Исходные данные: Logs/area-before-real-input.json; просмотренный снимок: Logs/area-before-real-square.png.

Очереди: карта 3000, клетки превью 3000, контур 2000. Изменение только очереди клеток в работающем Editor на 3008 вернуло заливку; просмотренный снимок Logs/area-layer-queue-probe.png подтверждает причину. Первые simulate_pointer команды не доставили событие начала в Update нового Input System; это не считается доказательством поломки игры. Далее использован QueueStateEvent без дополнительного InputSystem.Update: штатный цикл Unity обрабатывает события мыши и клавиатуры.

## Изменения

WorldOverlayMaterial задаёт явный порядок: карта 3000 → сетка 3005 → покров тумана 3010 → эффекты 3015 → клетки превью 3016 → контуры 3017 → стены 3020 → пинги 3030. Эффекты и измерения используют Dicebound/Markup: прозрачное смешивание, без записи глубины, отсечение по текущей видимости тумана. Материалы обновляются и для неподвижных областей; занавес подавляет отображение. Подпись расстояния учитывает выбранный источник предпросмотра.

Мерцание превью использует MaterialPropertyBlock и общий материал; материал не клонируется на каждую клетку. Материалы контуров и эффектов освобождаются вместе с объектами.
