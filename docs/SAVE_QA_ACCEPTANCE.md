## Надёжность отчёта тестов

Первый полный прогон завершился в логе редактора: 81 total, 80 passed, 0 failed (`save-qa-regression-log-summary.txt`); редактор затем был закрыт, полный CLI-отчёт не сохранился.
При повторных прогонах обнаружена ошибка наблюдения: CLI-запрос во время медленного сравнения миллионов образцов тумана получил таймаут главного потока и записал Error, который Unity Test Framework справедливо засчитал как падение текущего теста.
Полный XML (`save-qa-regression-cli-timeout.xml`) установил причину; игровая проверка размеров/кодирования масок не падала.
В существующем тесте сравнение NUnit заменено на `SequenceEqual` для обоих полных массивов: каждый образец по-прежнему проверяется. Целевой повтор прошёл (`save-qa-fast-mask-result.xml`).
Добавлен экспорт XML, который заново регистрируется после EnterPlayMode/перезагрузки домена. Он включается только при наличии `Logs/test-report-path.txt`; путь отчёта ограничен каталогом проекта. Повтор полной регрессии наблюдается чтением файла, без обращений к главному потоку редактора.
