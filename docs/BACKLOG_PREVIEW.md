# Рабочая Windows-сборка после 0.4.0

Папка: `Builds/BacklogPreview`. Запуск: `Dicebound.exe`. Для переноса нужна вся папка сборки, включая `Dicebound_Data`, DLL и остальные файлы рядом с EXE.

Это предварительная сборка ветки `codex/backlog-stabilization`. Новые изменения скомпилированы Unity; игровые сценарии после остановки тестовых прогонов не приняты. Номер следующего релиза не назначен.

## Настройки экрана

Кнопка **Настройки** находится внизу справа и доступна в лобби и игре. Можно выбрать разрешение, оконный режим, полноэкранный режим без рамки или обычный полноэкранный режим. После применения нужно подтвердить выбор за 15 секунд; иначе вернётся прежнее состояние.

Масштаб интерфейса меняется от 75% до 150% и сохраняется локально. Кнопка **100%** сбрасывает масштаб. Большие панели и меню уменьшаются, если не помещаются на экране.

## Прибытие между сценами

В панели мастера откройте **Сцена → Переходы**, нажмите **✎** у существующего перехода, затем **Точка прибытия на целевой сцене…**. В схеме целевой сцены выберите клетку и сохраните точку. Переключать живую сцену для выбора не требуется.

Серые клетки показывают препятствия, жёлтые — токены, зелёная — выбранную точку. При переносе выбранных токенов через этот переход они размещаются в ближайших свободных клетках. Если места недостаточно для всей группы, перенос отклоняется. **Сбросить** возвращает прежнее размещение без заданной точки. Смена целевой сцены перехода сбрасывает его точку прибытия.

## Состояния

На подписи токена показаны значки разрешённых состояний. Наведение на значок показывает название. Если состояний больше семи, **+N** показывает их полный разрешённый список при наведении. Те же значки есть в мастерском списке выбора состояний.

## Карты

В каталоге можно импортировать несколько файлов; в Editor выбирается папка. Ошибочный пакет отклоняется целиком. При повторном переходе карта может применяться из кеша текстур. Сервер и клиент сверяют SHA-256; если кеша нет, изображение передаётся обычным способом. Размер кеша ограничен с учётом активной карты.

## Справочник

Мастер редактирует записи во вкладке **Справочник** и выбирает **Игрокам доступно** или **Только мастер**. Игрок открывает **Справочник** внизу справа: там есть поиск по названию, тексту и тегам, категории, закреплённые записи и чтение содержания.

Игроки получают только открытые записи. Обновление открытого окна запрашивается раз в пять секунд; полная библиотека заменяется после получения и проверки всех частей.
