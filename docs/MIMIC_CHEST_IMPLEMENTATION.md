# Сундук мимика

Открытие: БУРМАЛДА / BURMALDA вне текстового поля. Для игры требуется сетевая сессия.

В мастерской: «Участники» → «Права игроков» → «Бурмалда». Список подключённых игроков, баланс каждого, пополнение +5 / +25 / +100 бурмалд. Уменьшение баланса не предусмотрено. Сервер определяет результат спина, списание и награды; клиент получает только собственный баланс. Стоимость 5, выплаты 19/30/60 сохранены.

Корпус: дерево по умолчанию; четыре факела дают бронзу; четыре щита, меча, зелья, свитка или ключа — серебро; четыре короны или d20 — золото; пять одинаковых по центру — алмаз. Применяется максимальная открытая ступень по текущему владельцу. Портрет и правила скрытия сохраняются.

Баланс и ступень сохраняются в PlayerPrefs хоста по нику, отдельно от файла кампании. Другой хост или другой ник означают отдельный прогресс.

Проверка: 56 самостоятельных C# проверок наград пройдены; после обновления Unity консоль не содержит ошибок. Внешний вид, анимация и отдельная пара host/client пока не проверены.

## Материалы и диагностика

Наградные материалы используют карты цвета, нормалей и свечения: гравировка и полированные полосы для металлов, гранёная структура для алмаза. Карты проверены через Unity Resources.Load.

Кнопка мастера «Создать 5 токенов для теста скинов» во вкладке «Бурмалда» создаёт пять обычных сетевых токенов с принудительными тестовыми материалами. Удаляются обычным способом. Тестовое переопределение действует в текущей сессии, не сохраняется в кампанию и не выдаёт награды игрокам.

Рычаг: серверный интервал сокращён с 1,6 до 1,3 секунды (анимация 1,4); отказ сервера явно снимает ожидание. Область клика расширена до изображения рычага, при доступном спине контур пульсирует золотым. Компиляция Unity и импорт карт проверены; повторные спины и пульсация в Play Mode ещё не проверены.
