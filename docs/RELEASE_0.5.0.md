# Dicebound 0.5.0

- Новый интерфейс Atlas: лобби, стол, меню игрока и панели мастера.
- Поле по умолчанию 500×500 клеток и поддержка больших состояний тумана.
- Улучшены инструменты разметки, палитры, индикатор тумана и управление сценами.
- Компактная панель кубов, новые иконки Phosphor, отдельные поля характеристик с модификаторами.
- Исправлено отображение подтверждений поверх открытых окон и сохранение пропорций иллюстрации лобби.

Windows x64. Распакуйте архив целиком и запустите Dicebound.exe.

Проверки: релизная сборка успешна, 0 ошибок, 488 предупреждений (в том числе шейдеры AI Inference). Windows Player запущен, поле 500×500 инициализировано, исключений в журнале запуска нет.

Известное ограничение проверки: из 53 целевых Unity-тестов 51 прошёл, 1 пропущен (явный онлайн Relay), 1 упал — StationaryPointerKeepsTokenInfoVisibleAndClearsWhenItLeaves. Отдельный повтор также не прошёл. Поведение подсказки под неподвижным курсором требует проверки; полная игровая приёмка и онлайн-Relay в этот выпуск не входят.
