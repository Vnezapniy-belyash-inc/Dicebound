# Настольный атлас — v2

Два изображения созданы встроенным imagegen по референсам v1; точные промпты в prompts.json. Лобби сохранено без изменений. Игровые файлы не изменялись.

- 01-gm-combat.png: компактная горизонтальная инициатива, прямой доступ к инструментам мастера во время боя, открытая строка редактора тумана, выбранный токен и контекстная карточка с параметрами/доступом/статблоком. Постоянная правая колонка убрана.
- 02-scene-preparation.png: настройки карты собраны в контекстную строку над картой, геометрия показана раскрывающимся меню, сохранён список сцен, карта занимает освободившееся пространство справа.

Допущения: экран 16:9, мышь и клавиатура; данные демонстрационные. Статические концепты, не внедрение. На втором макете открытое меню геометрии временно перекрывает поле масштаба — при закрытии оно освобождается. На первом карта и карточка токена показаны вместе с активной кистью тумана для демонстрации доступа; при реализации состояние карточки должно сохраняться при переключении инструментов, а редактирование токена требовать явного взаимодействия с карточкой.
