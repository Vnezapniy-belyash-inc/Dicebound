# Этап 2 — интерактивный прототип стола мастера

Открыть `index.html` обычным браузером. Рядом должны лежать `prototype.css` и `prototype.js`. Установка, сервер, интернет и запуск Unity не нужны. Данные живут только в памяти страницы, обновление страницы или «Сбросить пример» возвращает исходный пример.

Это отдельный прототип UX, основанный на atlas-stage1 / atlas-v2. Финальные ассеты и оформление этапа 3 не разрабатывались, реальная игра и сеть этапа 4 не подключались. Все цифры, участники, сцены, результаты кубиков и запросы — демонстрационные. Никакие файлы кампаний не читаются и не записываются.

## Что проверить кликами

1. **C / D / E.** Изначально бой включён, очередь раскрыта. «Следующий ход» меняет участника, после полного круга — раунд. «Бой включён» переключает в состояние вне боя со свёрнутой инициативой. Инструменты остаются доступны.
2. **Общая область D/E.** «Туман» раскрывает свои настройки непосредственно под общей строкой инструментов. «Геометрия» заменяет их на свои. «Выбор» убирает контекстную строку целиком. В бою C и D/E одновременно видимы. Активен только один инструмент.
3. **Токен.** В режиме «Выбор» клик по токену → «Информация»; ПКМ также открывает карточку. Токен можно перетащить по демонстрационной карте. Карточка имеет параметры, доступ и статблок; последние две вкладки показывают назначение существующих функций, без игровой интеграции.
4. **ХП.** Поменяйте поля или заполните дельту ±5, затем «Применить». Дельта применяется один раз и сбрасывается. Отрицательные/пустые/некорректные значения показывают ошибку. При уходе с изменённой формы появляется «Применить и продолжить / Отбросить / Остаться». В этом демо ХП ограничены интервалом 0…максимум — это допущение прототипа, игровую валидацию ещё нужно использовать при интеграции.
5. **Туман / геометрия.** На свободной карте клик оставляет условную отметку выбранного инструмента. «Отменить» откатывает последнюю деморазметку. Предпросмотр блокирует редактирование карты. Двери и препятствия представлены метками; реальные границы, раскрытие видимости и сетевые данные не вычисляются.
6. **Панели.** Сцены → токены → библиотека → мой лист: открыта одна содержательная панель. Смена сцены закрывает панель, выбор токена и инструмент; все сцены используют одну схематическую карту, загрузка/синхронизация не имитируются как настоящие. «Мой лист» отдельный и не зависит от выбранного токена.
7. **Кубики / журнал.** Нажмите dN, откройте журнал. Здесь используется простой случайный результат, а не физические кубики Unity. Док можно свернуть.
8. **Перемещения.** Индикатор открывает модальное рассмотрение двух демозапросов. Разрешение/отклонение удаляет запрос из демосписка и обновляет счётчик; токен в игре не перемещается. Закрытие не разрешает запрос.
9. **Esc.** Закрывает модальное окно; при вводе сначала снимает фокус поля; затем завершает активный инструмент; затем закрывает панель с защитой несохранённых полей; затем снимает выделение. Один Esc — один шаг. ПКМ при активном инструменте возвращает к выбору.
10. **Узкое окно.** При ширине ≤850 px навигация компактнее, инициатива показывает текущего/следующего, строка инструментов прокручивается, панель становится нижней карточкой. Карта под открытой карточкой не принимает указатель. CSS предусмотрен, визуальная проверка браузером пока не выполнена.

## Границы прототипа

Прототип интерактивно демонстрирует маршруты и состояния, а не реализует все команды продукта. Файловые диалоги, каталог карт, настройка публичности, редактирование статблоков/справочника, полный редактор инициативы, состояния токена и импорт/экспорт листа имеют честные пояснения о последующем подключении. Создание демотокена, базовая карта и переключение вкладок доступны для проверки компоновки. Автоматических атак, автоматического урона или облачных сохранений нет.

## Проверка

- `node --check prototype.js` — синтаксис корректен.
- `node check-prototype.cjs` — 18 проверок состояния и обработчиков через минимальный DOM-адаптер, PASS. Результат в `verification.json`.
- Проверены переход боя/инструментов, контекстная область, ХП и однократная дельта, валидация, защита черновика, одна панель, локальный лист, разметка/отмена/предпросмотр, переключение сцены, журнал и запросы, Esc, делегирование кнопки +5, отсутствие сетевых вызовов.
- Это **не** проверка в настоящем браузере, CSS или физических кликов. Встроенный браузер запретил открытие локального `file://`; обход не выполнялся. Скриншота готового прототипа нет. Реальную читаемость, прокрутку, фокус после перестроения DOM и размер окна нужно оценить при открытии HTML пользователем.
