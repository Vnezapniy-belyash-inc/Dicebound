# Atlas: перестройка нативного интерфейса

Дата: 4 ноября 2026. Основа: утверждённые концепты и `docs/ui-concepts/atlas-stage3/`.

## Изменения

Удалены старые построители основного HUD DiceUI. Новый AtlasCanvas строит шапку сессии, навигацию мастера, компактную инициативу, инструменты с контекстными настройками, временную карточку токена и журнал. У игрока инструменты, формы областей и шесть цветов находятся слева; горизонтальной панели инструментов нет. Существующие обработчики игровых и сетевых действий сохранены.

Перестроены лобби, лист персонажа, окно инициативы, настройки и согласование движения. Мастерская получила вертикальные категории и формы с прокруткой; существующие поля и связи с данными перенесены в новую компоновку. Публичный справочник использует разрешённые сервером записи. Карточка токена разделена на параметры, доступ и статблок.

## Проверка

- Unity 6000.5.1f1: импорт, компиляция и реально запущенный Play Mode.
- Целевой набор Atlas / UiInput / InitiativeProjection / LobbyIntegration: 23 passed, 0 failed, 1 ignored (явный онлайн-Relay). Job `7e933b8576de4bc7a2122e320ac77168`.
- После последних правок: Atlas 3/3 passed. Job `3320cbb4b74541cf91f00606449081d0`.
- Editor-клиент подключён к отдельному Windows Player-хосту: connected=true, host=false. Перетаскивание области и выбор синего цвета через Input System: палитра доступна, получены 44 серверные клетки, инструмент завершён. `Logs/atlas-rebuild/client-area-input.json`.
- Визуально просмотрены лобби, мастер, игрок, карточка токена, настройки, мастерская, статблоки и лист. Размеры Game View: 1672×723, 1600×900 и 1280×960. Последняя проверка консоли: 0 errors.
- Во временном сценарии ввода был дефект QA callback: он обращался к кнопке после её удаления; стек MCPDynamicCode, не runtime-код игры. Callback завершился, устройства и InputSettings восстановлены. При последующих проверках runtime-ошибок нет.
- Тестовые хост и Play Mode остановлены. Сцена и тестовые данные не сохранялись, автосохранение отключено. Новая распространяемая сборка не выпускалась; QA host использовал предыдущую совместимую сборку.

## Границы проверки

Это новая реализация структуры прототипов, а не заявление о пиксельном совпадении всех экранов. Окончательная визуальная приёмка остаётся пользователю. Онлайн-Relay, полный проход всех команд мастерской и сборка для распространения в этот проход не проверялись.
