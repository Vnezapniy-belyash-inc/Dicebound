# Колесо приколов и советы

Актуально на 17 октября 2026 года. В локальном проекте реализованы колесо на T, броски, штампы и советы. Ручная шторка мастера отделена от автоматической синхронизации сцены. Визуальная приёмка в живой игре остаётся отдельно.

## FUN-03 — колесо приколов на удержание T

- [x] Всем игрокам доступна клавиша `T`.
- [x] При нажатии и удержании `T` открывается радиальное колесо.
- [x] Выбор сектора происходит наведением мыши, без дополнительного клика.
- [x] При отпускании `T` помидор/яйцо сразу запускается; для штампа открывается ввод текста без отправки события до подтверждения.
- [x] В колесе есть явный выбор «Отмена»; отпускание без выбранного прикола также отменяет действие.
- [x] `Esc`, потеря фокуса окна и разрыв соединения закрывают колесо без запуска эффекта.
- [x] Колесо не открывается при вводе текста. Пока оно открыто, движения мыши и отпускание клавиши не запускают перемещение токенов или другие инструменты.

Предлагаемый порядок взаимодействия: сначала навести курсор на место на карте или на токен, затем зажать `T`. При открытии запомнить исходную цель и позицию. Перемещение курсора по колесу выбирает прикол, но не меняет исходную цель. Отпускание `T` применяет прикол к запомненному месту. Центральная область колеса — «Отмена».

Секторы: помидор, яйцо, «Штамп». Выбор штампа открывает окно ввода текста; подтверждение кнопкой или Enter, отмена кнопкой или Esc. Геометрия и поведение — по аналогии с колесом чата, которое описал пользователь; наличие готового компонента колеса в проекте перед реализацией проверить отдельно.

Приёмка: полный сценарий выполняется удержанием, наведением и отпусканием; отмена ничего не отправляет в сеть; эффект появляется в исходной точке, а не под сектором колеса.

## FUN-04 — броски, штампы и временные следы

- [x] Помидор летит в выбранную точку и оставляет шлепок.
- [x] Яйцо летит в выбранную точку и оставляет кляксу с кусочками скорлупы.
- [x] Реализовать полёт через 2D PNG, без обязательных 3D-моделей: предмет появляется крупным сверху экрана, движется к выбранной точке на карте/токене, уменьшается по мере приближения и слегка вращается.
- [x] При попадании быстро расплющить изображение предмета и заменить его отдельным прозрачным PNG следа: помидор — шлепок, яйцо — клякса со скорлупой. След остаётся несколько секунд и плавно исчезает.
- [x] Подготовить отдельные прозрачные PNG для летящего помидора, летящего яйца и каждого следа попадания. Эти ассеты также может сгенерировать Codex; 3D-модели для согласованного варианта не нужны.
- [x] Один произвольный штамп вместо готовых надписей: ввод до 80 символов, подтверждение кнопкой/Enter, отмена кнопкой/Esc.
- [x] Сам рисунок и текст каждого штампа окрашиваются в назначенный игроку цвет. Цвет брать из реестра игроков, на сервере — по отправителю действия.
- [x] Жирный текст и толстая рамка; ширина расширяется под текст, длинная надпись переносится на две строки вместе с рамкой.
- [x] Полёт и результат видны всем подключённым игрокам.
- [x] Следы остаются на карте и поверх токенов несколько секунд, затем исчезают. Стартовое предложение: 5 секунд после попадания и короткое плавное исчезновение; точную длительность можно настроить при реализации.
- [x] Попадание по токену оставляет след, привязанный к токену: при его движении след перемещается вместе с ним. Попадание по карте оставляет след в мировой позиции.

Сетевой вариант: игрок отправляет тип эффекта и цель; сервер определяет автора/цвет и рассылает компактное событие. Локальные клиенты воспроизводят анимацию и удаляют след по времени. Передавать идентификаторы ассетов и координаты, а не PNG-файлы. Временные следы не сохраняются как постоянные объекты кампании.

Для карты учитывать туман и порядок отрисовки; эффекты не должны раскрывать скрытые токены или геометрию. Для токена использовать отдельный слой поверх его видимого изображения. При исчезновении цели эффект корректно удаляется.

Уточнение пользователя: помидор, яйцо и их следы сохраняют естественные, примерно реалистичные цвета. Цвет автора применяется только к штампам.

Приёмка: эффекты доступны обычному игроку, совпадают у хоста и клиентов, перекрывают видимую карту/токены, держатся несколько секунд и исчезают; штампы используют именно назначенный цвет автора; пользовательский текст совпадает у участников.

## FUN-05 — случайные советы поверх мема

Статус: пользователь не увидел советы при проверке. Исправлена двойная отрисовка полноэкранного мема и немедленное заполнение текста. Три целевые проверки прошли; задача не принята до подтверждения в игровом окне.

- [x] Добавить короткую подпись внизу ручной шторки мастера, поверх уже добавленного мема.
- [x] Случайный совет появляется сразу при показе шторки, затем меняется каждые 20 секунд.
- [x] Выбор выполняется локально у каждого игрока, без синхронизации с хостом и другими клиентами.
- [x] Все советы написаны строчными буквами.
- [ ] Подпись читается на картинке, не обрезается на разных разрешениях и не закрывает её основную надпись.

Предложение по выбору: случайный порядок без немедленного повтора одного и того же совета. Для отсчёта использовать реальное время, чтобы пауза игрового времени не останавливала смену текста.

Утверждены только эти десять советов:

1. «чтобы победить дракона, попробуйте снизить его здоровье до нуля»
2. «зелье неизвестного происхождения становится известным после употребления»
3. «этот совет не требует концентрации»
4. «короткий отдых занимает меньше времени, чем длинный»
5. «чтение этого совета не расходует действие»
6. «советы на экране загрузки появляются во время загрузки»
7. «у зомби hp обычно меньше, чем у тараска»
8. «при стрельбе из лука расходуются стрелы»
9. «скелет весит меньше человека, из которого он получился»
10. «после продажи меча у вас становится больше денег и меньше меча»

Другие варианты из переписки не включать автоматически.

## Проверка

Сетевые проверки охватывают типы эффектов, цвет автора, цели, скрытые токены, повторные запросы и удаление следов. Вручную проверить колесо, отмену, ввод текста, разные размеры экрана и масштабы камеры. Штампы имеют анимацию постановки и увеличены на 50%.

Ассеты: [FUN_ASSETS.md](FUN_ASSETS.md). Проверка: [FUN_VERIFICATION.md](FUN_VERIFICATION.md).

Произвольный штамп: цель запоминается до открытия колеса и сохраняется при вводе; для движущегося токена используется локальная точка попадания. Во время ввода заблокированы действия со столом и игровые горячие клавиши. Пустой текст не отправляется, сервер проверяет длину. Закрытие окна, потеря фокуса, отключение или смена сцены отменяют ввод. Полёт, краткий след, цвет автора и увеличение на 50% сохранены.
